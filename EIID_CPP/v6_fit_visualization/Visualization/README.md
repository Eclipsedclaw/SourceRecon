# Visualization — Developer README

Visualization is an independent ROOT executable that reads only `result.root` and truth JSON. V6 adds a shared fit-analysis service and three diagnostic plots to the original sky map, spectrum, and containment plots.

## Components

- `IPlotter`: polymorphic plot plugin interface.
- `VisConfig`: plotting, fitting-window, and truth configuration.
- `ReconstructionDataReader`: one-time ROOT reader shared by all plugins.
- `PlotUtils`: coordinate, HEALPix-resolution, binning, and marginalization helpers.
- `SkymapPlotter`, `SpectrumPlotter`, `ContainmentPlotter`: original physics views.
- `FitAnalyzer`: one preliminary energy fit, an energy-gated local tangent-plane direction fit, a direction-gated final energy fit, and containment metrics.
- `EnergyFitPlotter`: local Gaussian-plus-constant energy fit and residuals.
- `DirectionFitPlotter`: elliptical 2D Gaussian with 1σ/2σ ellipses in a spherical tangent plane.
- `EnergyAnglePlotter`: reconstructed intensity versus energy and angular distance from truth.
- `FitSummaryWriter`: machine-readable `fit_summary.json`.
- `vis_main.cpp`: composition root; one immutable `FitAnalysisResult` is shared by enabled consumers.

Peak selection never uses truth. Truth is used only for markers, containment, and bias. Direction is fitted in a local spherical tangent plane rather than as independent theta/phi distributions.

To add a plot, implement `IPlotter`, add the source under `src/`, and register it in `vis_main.cpp`; the wildcard Makefile compiles it automatically.

MLEM image weights are correlated and are not independent Poisson counts. Fit centres and widths are descriptive comparison metrics, not formal confidence intervals. Direction widths below the mean HEALPix pixel scale are flagged as under-resolved.

The standalone Makefile reads ROOT, JSON, and rpath settings from `../config/local.mk`, generated by root-level `make configure`.
