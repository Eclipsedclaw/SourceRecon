# GridResampler — Developer README

GridResampler converts an absolute-efficiency map from a Master direction–energy grid to a Target grid. It is both independently executable and strategy-driven.

## Files

- `ResamplerConfig`: JSON parsing and Master/Target validation.
- `IInterpolationStrategy`: plug-in interface.
- `NearestInterpolation`: nearest HEALPix center and nearest energy point.
- `PolygonInterpolation`: equal-area common-refinement overlap weighting and linear energy interpolation.
- `GridAdapter`: owns both grids and constructs the selected strategy.
- `ResamplerIO`: strict schema read/write; source radius and efficiency definition are preserved.
- `resampler_main.cpp`: independent composition root.
- `Makefile`: builds `grid_resampler` and invokes `common` when necessary.

## Polygon method

Master and Target pixels are projected onto a common, finer HEALPix grid. Because those micro-pixels are equal area, the number mapped to a Master–Target pair estimates their spherical overlap area. `polygon_subdivision_factor` increases the common Nside and convergence cost.

The method averages an efficiency field over Target pixel area. It does not sum efficiencies, because each target value remains a probability.

## Plug-in rule

A new method implements `IInterpolationStrategy::resample`. Register it only in `GridAdapter`; ROOT I/O and `main.cpp` remain unchanged.

The standalone Makefile reads ROOT, HEALPix, JSON, and rpath settings from `../config/local.mk`, generated by the root `make configure` target.
