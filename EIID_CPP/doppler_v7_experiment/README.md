# Doppler V7 exploratory experiment

This directory is an isolated ablation study derived from V7, not a formal V8 release. It compares a free-electron Klein–Nishina reference with Livermore and optional LowEP Compton models for two-layer escape-Compton events. Full absorption and energy closure are deliberately not required.

See [README_CHN.md](README_CHN.md) for the complete setup, commands, outputs and interpretation rules.

Quick start:

```bash
make configure
make all
make experiment
```
