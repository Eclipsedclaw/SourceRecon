# EIID V9 response-model experiment — developer guide

V9 derives from V8 and compares three pluggable ARM response kernels against the same external event data: a double Gaussian, a Voigt convolution, and an independent-width Gaussian–Lorentzian mixture. V8 is untouched.

```text
v9_response_mixture_experiment/
├── common/                 HEALPix grid, physics types, efficiency container
├── Geant4_Simulation/      master absolute-efficiency simulation
├── GridResampler/          master-to-reconstruction grid conversion
├── DopplerSampleGenerator/ response-calibration Monte Carlo
├── SimulationSupport/      shared calibration schema
├── ResponseCalibration/    three fitters and convergence diagnostics
├── ResponseKernel/         interface and runtime-selectable kernels
├── Reconstruction/         EIID/LM-MLEM engine
├── KernelBenchmark/        comparison of usable models only
├── Visualization/          per-model plots
├── Translator/             optional raw-step event translator
├── scripts/prepare_run.sh  safe run archiving and setup
├── events.root             external input; never generated by V9
├── runs/latest/            centralized current output
└── Makefile                top-level build and workflow
```

The new mixture is

\[
p(x)=(1-\eta)G(x;\mu,\sigma)+\eta L(x;\mu,\Gamma),
\]

with independent Gaussian and Lorentzian widths. It models two event populations and is intentionally not named pseudo-Voigt.

`ResponseCalibration` records ROOT fit status, covariance status, EDM, call count, and convergence for every required calibration bin. A model is usable only if all required bins converge. An unusable model is retained in calibration diagnostics but excluded from reconstruction, benchmarking, and visualization; no per-bin fallback is allowed.

`KernelBenchmark` combines held-out calibration test NLL, AIC, and BIC with final-image peak errors, energy width, and R50/R68/R90. These metrics retain their separate physical meanings instead of being collapsed into an arbitrary scalar score. A Voigt model that fails the convergence gate is recorded as skipped rather than replaced by a stale result or another kernel.

`make experiment` first validates the user-supplied `events.root`, archives a previous `runs/latest`, then regenerates efficiency, calibration, eligible reconstructions, benchmark output, and figures. See `MANUAL.md` for commands and configuration fields. Each module has its own developer README and user manual.
